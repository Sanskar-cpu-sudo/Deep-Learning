
# Deep Learning Assignments

Collection of 10 Deep Learning assignments implemented using **Python, TensorFlow/Keras, and Jupyter Notebook/Google Colab**.

## Assignments

### 1. Data Preprocessing and Visualization

Installed and configured TensorFlow/Keras and performed data preprocessing, normalization, train-test splitting, and data visualization on a sample dataset.

### 2. Multilayer Perceptron (MLP)

Designed and implemented an MLP for classification using the Iris dataset. Model performance was evaluated using accuracy and a confusion matrix.

### 3. Forward Propagation and Backpropagation

Implemented forward propagation and backpropagation using TensorFlow/Keras. Analyzed the effect of different learning rates and numbers of epochs on model performance.

### 4. LSTM Time-Series Forecasting

Developed an LSTM-based model for time-series forecasting. The model was trained to learn patterns from sequential data and predict future values.

### 5. RNN, LSTM and GRU Comparison

Implemented RNN, LSTM, and GRU models for sequence classification. Compared their performance using suitable evaluation metrics.

### 6. CNN Image Classification

Designed and implemented a CNN for image classification using a plant disease dataset. The model was trained to classify different disease categories.

### 7. Transfer Learning

Implemented transfer learning using pre-trained AlexNet, VGG16, ResNet50, and EfficientNetB0 models. Compared their classification performance.

### 8. BERT Text Classification

Implemented a pre-trained BERT model for sentiment analysis/text classification. Evaluated the model using appropriate classification metrics.

### 9. Vision Transformer (ViT)

Implemented image classification using a pre-trained Vision Transformer (ViT). Its performance was compared with a CNN-based model.

### 10. Audio Classification

Developed a deep learning application for audio classification incorporating Speech-to-Text (STT) and Text-to-Speech (TTS). The model was evaluated using suitable performance metrics.
